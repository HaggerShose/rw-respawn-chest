Hello everyone,

you probably know the problem: there are loot chests at spawn, someone empties them, and sooner or later an admin has to refill them by hand.


Respawn Chest takes care of exactly that.

Fill a chest once and save its contents as a template. As soon as a player removes an item, a timer starts. When the timer expires, the chest is cleared and restored to its saved contents.


The plugin is deliberately lightweight. Registered chests are not constantly checked in the background, so even a large number of them should have practically no noticeable impact on server performance.

Das Plugin ist bewusst leichtgewichtig aufgebaut. Registrierte Kisten werden nicht ständig im Hintergrund abgefragt, weshalb auch eine große Anzahl davon praktisch keinen spürbaren Einfluss auf die Server-Performance haben sollte.

How it works

  • Place and fill a normal chest
  • Look at the chest
  • Use [tt]/make-refill <minutes>[/tt] in Chat
  • A player removes an item
  • The refill timer starts
  • The world keeps turning
  • When the timer expires, the chest is cleared and restored from the saved template


Putting items into the chest does not start the timer.

If a timer is already running, removing additional items does not restart or extend it.

Automatic resets happen silently, without chat spam.

So funktioniert es

  • Normale Kiste platzieren und befüllen
  • Kiste anschauen
  • [tt]/make-refill <minutes>[/tt] im Chat eingeben
  • Ein Spieler nimmt ein Item heraus
  • Der Respawn-Timer startet
  • Die Welt dreht sich weiter
  • Nach Ablauf wird die Kiste geleert und aus dem gespeicherten Template wiederhergestellt


Items hineinzulegen startet keinen Timer.

Läuft bereits ein Timer, wird er durch weitere Entnahmen weder neu gestartet noch verlängert.

Der automatische Reset erfolgt still und erzeugt keinen Chat-Spam.

Commands

Only server admins listed in Server_Admins in server.properties can use these commands.

  • /make-refill <minutes> – registers the targeted chest and saves its current contents as the template.
    it also can be used to update a timer of an already registered chest
  • /refill-update – replaces the saved template with the chest's current contents
  • /refill-now – resets the chest immediately
  • /refill-remove – unregisters the chest
  • /refill-info – shows the current refill status


A value of 0 minutes uses a 5-second timer for testing.

Maximum refill time: 24 hours.

Important: When a chest resets, everything currently inside it is removed before the saved template is restored.

The chest is not a hotel. It is a template with discipline.

Befehle

Nur Server-Admins aus Server_Admins in server.properties können diese Befehle verwenden.

  • /make-refill <minutes> – registriert die anvisierte Kiste und speichert ihren aktuellen Inhalt als Template
    kann auch dazu verwendet werden den Timer einer schon registrierten Kiste zu updaten
  • /refill-update – ersetzt das gespeicherte Template durch den aktuellen Inhalt der Kiste
  • /refill-now – setzt die Kiste sofort zurück
  • /refill-remove – entfernt die Kiste aus dem Plugin
  • /refill-info – zeigt den aktuellen Status der Kiste


0 Minuten entsprechen zum Testen einem Timer von 5 Sekunden.

Maximale Respawn-Zeit: 24 Stunden.

Wichtig: Beim Reset wird der komplette aktuelle Inhalt der Kiste entfernt, bevor das gespeicherte Template wiederhergestellt wird.

Die Kiste ist kein Hotel, sondern ein Template mit Disziplin.
